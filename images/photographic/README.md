# Photographic interpretation

`grand-gate.png` is an AI-generated architectural interpretation, made with the
built-in image generation tool using `images/photoreal/veo_grand_gate_open.jpg`
as its reference. It is not a photograph of a real place or a capture from the
interactive 3D world.

Requested direction: photographic limestone triumphal arch, weathered gilded
gates, natural alpine planting, physically plausible afternoon light, fine
masonry detail, and restrained atmosphere; avoid a game render, plastic surfaces,
sparkles, and oversaturated colors.

The tool returned **1672 × 941 pixels**, despite a requested 3840 × 2160 output.
The original output is preserved without upscaling. It must not be advertised
as native 4K.

The remaining photographic destinations reuse the existing site images.
